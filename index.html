About Me

Android Developer based in Algeria, specializing in professional tooling for industrial electrical engineering. My work centers on building field-grade applications where reliability, data integrity, and security are non-negotiable — the kind of software engineers trust in day-to-day operations, not just on a demo screen.

  • Architecture — Kotlin-first, Jetpack Compose UI, Room persistence, MVVM with reactive state.
  • Security — FLAG_SECURE, AES-256-GCM via Android KeyStore, hardened network security config, ProGuard log stripping.
  • Reliability — Offline-first data, encrypted cloud backup (Google Drive & OneDrive via rclone), scheduled exports.
  • Accessibility — Trilingual localization (English, French, Arabic) with full RTL support.

Current focus: ElecPilot, a complete Android solution for managing motor starters and PLC I/O modules in industrial environments, and OpenCode Free Radar, a tracker for AI models free to use with OpenCode.
